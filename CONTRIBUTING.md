# Contributing to KANser

Thanks for your interest in contributing to KANser.

KANser is a research prototype exploring agentic AI for lung cancer assessment. Contributions that improve documentation, reproducibility, reliability, and code quality are welcome.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork and create a separate branch for your changes.
3. Read `README.md` and `WALKTHROUGH.md` to understand the project structure and setup.
4. Configure the environment using the provided example environment file.
5. Follow the existing setup instructions before running the application or tests.

## Types of Contributions

You can contribute by:

- Improving documentation and setup instructions.
- Adding tests for existing functionality.
- Improving evaluation reproducibility.
- Fixing bugs and improving error handling.
- Reviewing security and reliability issues.
- Improving the clarity of research limitations and safety documentation.

## Guidelines

- Keep changes small and focused.
- Avoid unrelated modifications.
- Do not commit API keys, passwords, tokens, or real patient information.
- Do not introduce new dependencies without a clear reason.
- Preserve existing behaviour unless a change is intentional and documented.
- Do not present research-prototype outputs as clinically validated results.
- Document the purpose of each change and any relevant limitations.

## Testing

Run the relevant existing tests for the files you modify, following the commands documented in the repository.

For evaluation-related changes, use the existing evaluation dataset and validation script where applicable. Do not use reference predictions as actual model results.

## Pull Requests

Before opening a pull request:

1. Review your changes and remove unrelated edits.
2. Run the relevant checks.
3. Explain the problem your contribution addresses.
4. Describe the changes and how you tested them.
5. Mention any limitations or follow-up work.

Thank you for helping improve KANser!
